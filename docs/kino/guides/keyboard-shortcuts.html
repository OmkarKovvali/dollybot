Presets and custom keys

Open Settings > Keyboard shortcuts, then choose Kino or Premiere Pro. Your edits are saved separately for each preset on this device.

Premiere Pro preset

Keyboard shortcuts⌘⌥K
Split all tracks at playhead⌘⇧K
Add edit to selected tracks⌘K
Ripple delete across tracks⌥⌫or⇧⌦
Zoom in=
Zoom out-
SnappingS

Add Edit uses tracks containing selected clips while the timeline has focus. ⌘⌥K opens keyboard shortcuts; ⌘⇧P opens Kino’s actions. Ripple delete keeps existing gaps.

Changing keys

Change
Click an action’s keys and press new ones. Plus adds another; remove clears one.
Modified
Shows the selected preset’s edits, including cleared keys.
Reset
Reset at the top restores only the selected preset. Each row resets one action. A named preset returns to its original keys.
Limits
Tool and range keys still use Kino defaults. Space and timeline copy and paste stay fixed.

Ask Kino Agent

Kino Agent can switch presets and keep your custom keys, or turn a screenshot of another editor’s keyboard map into a named preset. It maps only commands Kino has, shows you the changes and waits for your confirmation.
