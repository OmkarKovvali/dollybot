Prompting

Use Kino’s chat, an agent connected over MCP, or a cloud agent.

Mention projects you like

Type @ in Kino to pick a project, or paste its link into your agent’s chat. Describe what to reuse, such as its branding or pacing.

Add motion graphics and B-roll over this A-roll in @SemiAnalysis Brand to illustrate the point. Add enough padding for social media viewing on phones.

To start a brand from a website, see Brand matching.

Use skills

Type / in Kino to pick a skill, such as /brand-clone-video. Settings → Skills lists them. Ask the agent to save useful instructions as a skill so you can reuse them.
